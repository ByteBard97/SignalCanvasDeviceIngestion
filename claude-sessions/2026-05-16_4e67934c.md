# Session 2026-05-16 (4e67934c)

## What Was Accomplished

This was a massive infrastructure session spanning two days (May 14-16). The primary goal was building systematic tracking and organization for the SignalCanvas Device Library.

### Device Library Infrastructure (SignalCanvasDeviceLibrary)

Built the full quality tier system from scratch:

- **Migration**: Ran `split_with_provenance.py` — migrated 4,086 devices from `manufacturers/` bundle format to individual `patches/<manufacturer>/<slug>.patch` files. Each file now has `quality`, `source`, and `bridge_status` in its meta block. 3,212 orphan (consumer/IT) devices deleted. `manufacturers/` and `lib_split/` removed.
- **Quality tiers**: D (auto-converted), C (pipeline), B (handcrafted), A (human reviewed). All 4,069 patch files pass lint.
- **Pre-commit hook**: Blocks any commit of a `.patch` file missing required meta fields.
- **`excluded.csv`**: Denylist for devices that should never be selected for pipeline processing. 31 entries as of session end (CIT switches, cables, consumer gear, OOS devices).
- **`excluded_codes.md`**: Defines reason codes (CIT, OOS, DUP, DSC, NDS) for LLM and human readability.
- **`select_devices.py`**: New script — randomly picks N D-tier devices from `patches/`, skips `excluded.csv` and already-processed devices from manifest DBs, enforces max-per-manufacturer. 3,099 eligible devices as of session end.
- **6 missing B-tier devices** from `frontend/lib/` added to library (AJA GEN10, ClearCom LQ-2W2, GreenGO MCX, Luminex LumiNode 1, Shure ADX5D, Yamaha SWP1-16MMF).

## Key Decisions

- Quality in metadata, not folder paths — re-tiering is a field update, not a file move.
- `excluded.csv` with short reason codes (CIT/OOS/DUP/DSC/NDS) rather than JSON — LLM-readable, no repeated labels.
- `_uncategorized/` folder skipped by selection script automatically (793 devices with no identified manufacturer).
- Display sinks (TVs, monitors) excluded from library — they don't add value to signal flow diagrams.
- Rolling pipeline target size: 20 devices (not 200) — conservative until pipeline stability is confirmed.
